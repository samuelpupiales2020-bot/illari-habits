# Illari – Hábitos que amanecen

Página web y app móvil (PWA) de hábitos para estudiantes.

**Autor:** Cristian Samuel Pupiales Martinez – Ingeniería de Software, primer semestre
**Demo:** https://illari-habits-1e2733.netlify.app

## Funciones
Hábitos con categorías, rachas, XP y niveles, ánimo diario, progreso (gráfica y mapa de calor), 12 logros, modo enfoque (Pomodoro), modo oscuro/claro y respaldo en JSON.

## Tecnologías
HTML5, CSS3 y JavaScript (ES6) sin librerías. PWA con manifest.json y service worker. Datos en localStorage.

## Cómo ejecutarlo
Abre `index.html` en el navegador o súbelo a Netlify (https://app.netlify.com/drop).
